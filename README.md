DZ 53. Bootstrap repetition task

1. Creating a resume page
2. Create a simple one-page web page using Bootstrap 5. Use only basic components and classes.

Page requirements:

1. Navbar
- Logo or name on the left.
- Links to sections: About, Skills, Projects, Contact.
- The bar should be fixed at the top.
  
2. About section
- Use container for structure.
- Add your photo (or stub) in one column and a text description in another.
- Use row and col for division.

3. Skills section
- Add a list of skills (e.g. HTML, CSS, JavaScript) in the form of progress bars.
- Use the progress component.

4. Projects section
- Create cards for each project.
- Use an image, title, and short description in the cards.

5. Contact Section
- Form with fields: name, email, message and a "Submit" button.
- Use form-control for inputs.

6. Footer
- Add a footer with text like "© 2024 Your Name. All Rights Reserved."
- Use text-center for centering.

Additional requirements:
- Use Bootstrap classes for styling, avoid adding your own CSS styles.
- The page should look good on mobile devices (check responsiveness).

Result:

After completing the task, you will receive a responsive page with basic Bootstrap components.
