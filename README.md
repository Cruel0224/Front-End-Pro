You need to write your own implementation of the todo list, taking the files from the lesson as a basis - todo list.

You can reuse the layout from the html file, but you need to write all the JS yourself.

Writing via MVC and Function constructors is mandatory

The test must be submitted in a native way

- Draw a diagram of the work before writing the code
- Write the code (algorithm and examples below)


What needs to be done -

- Collect data from the form
- Check the data
- based on the collected data, generate an element for display on the page
- Insert the element on the page when submitting the form
- clear the form
- Also, you need to store an array of todo item objects in localStorage, after reloading the page (if the data is in localStorage) render them where they were before loading.
